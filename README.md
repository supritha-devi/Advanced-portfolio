## About the Project

This portfolio website was developed as part of an **Advanced CSS3 & Responsive Architecture** internship task.

The project focuses on creating a visually refined and fully responsive portfolio using modern front-end development practices. The design combines a warm, editorial-inspired visual direction with a structured and maintainable CSS architecture.

The interface is designed to provide a consistent experience across mobile, tablet, and desktop devices.

## Responsive Architecture

The website follows a **mobile-first responsive design approach**.

### Mobile

Optimized navigation, typography, spacing, and content structure for smaller screens.

### Tablet

Responsive Grid and Flexbox layouts adapt the content to medium-sized screens.

### Desktop

A structured multi-column layout provides improved visual hierarchy and spacing for larger screens.

---

## CSS Architecture

### CSS Grid

CSS Grid is used for page-level layouts where both rows and columns need to be controlled.

### Flexbox

Flexbox is used for localized component layouts such as navigation, buttons, cards, and content alignment.

### CSS Custom Properties

CSS variables are used to manage reusable colors, spacing, typography, and theme-related values.

### Responsive Media Queries

Media queries allow the interface to adapt across different viewport sizes while maintaining usability and visual consistency.
